## Formula recall

| Need | Formula |
|---|---|
| Buy shares | I = nM; n = I/M |
| Dividend | d = Fr/100; D = nd |
| Required income | n = D/d; I = DM/d |
| Dividend rate | r = 100D/(nF) |
| Yield and its inverses | y = 100D/I = Fr/M; M = Fr/y; r = yM/F |
| Sale proceeds | nSold × sale price |
| Capital gain | nSold × (sale price − purchase price) |
| Reinvestment | new n = available cash/new M |
| Income change | new annual dividend − old annual dividend |

**Three final checks:** Did I use face value for dividend? Market price for buying/selling? The requested denominator for a percentage?
